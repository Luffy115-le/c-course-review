🎴 Day1-Day4 知识卡片合集

点击卡片查看详情，按章节和分类筛选

基础
CPU
中央处理器
计算机的大脑，负责执行程序指令和运算。
💡 核心部件，相当于人的大脑
基础
内存 RAM
随机存取存储器
临时存储正在运行的程序和数据，断电后数据丢失。
⚠️ 断电即失，速度快容量小
基础
硬盘
外部存储
永久存储数据，断电后数据不丢失。
💡 速度慢容量大，永久保存
重点
冯·诺依曼结构
计算机五大组成
运算器、控制器、存储器、输入设备、输出设备。
📌 必考：五大部件名称及功能
重点
位 / 字节
存储单位
1 字节(byte) = 8 位(bit)。基本存储单位。
📌 1B = 8bit，KB=1024B，MB=1024KB
重点
二进制
计算机语言
计算机只识别 0 和 1，所有数据都用二进制表示。
📌 逢二进一，0b 前缀表示二进制
必考
原码 / 反码 / 补码
负数表示
原码=符号位+绝对值；反码=原码除符号位取反；补码=反码+1。
⚠️ 计算机用补码存储负数！
重点
ASCII
字符编码
美国标准信息交换码，用 7 位二进制表示字符。
📌 'A'=65, 'a'=97, '0'=48
补充
GB2312 / UTF-8
中文编码
GB2312 简体中文，UTF-8 通用编码，兼容 ASCII。
💡 当前主流使用 UTF-8
重点
操作系统
系统软件
管理硬件资源，提供用户接口，常见：Windows、Linux、macOS。
💡 Linux 是开发常用系统
必考
#include
包含头文件
引入标准库或自定义头文件。#include <stdio.h> 引入输入输出库。
⚠️ 头文件以 .h 结尾
必考
main()
主函数
程序入口，每个 C 程序必须有且仅有一个 main 函数。
📌 int main() 或 int main(int argc, char* argv[])
必考
printf()
输出函数
向屏幕输出信息，需要引入 stdio.h。
📌 printf("格式字符串", 参数);
重点
return 0
返回值
main 函数的返回值，0 表示程序正常结束。
💡 返回非 0 表示异常
重点
注释
代码说明
// 单行注释，/* ... */ 多行注释，不参与编译。
💡 注释是写给人看的，编译器忽略
基础
分号 ;
语句结束符
每条语句必须以分号结尾，表示语句结束。
⚠️ 忘记加分号是最常见错误！
重点
数据类型
变量类型
int(整型)、float(浮点)、double(双精度)、char(字符)。
📌 变量必须先声明后使用
基础
变量声明
定义变量
数据类型 变量名; 如 int age; char name[20];
💡 变量名只能包含字母、数字、下划线，不能以数字开头
重点
scanf()
输入函数
从键盘读取输入，需要 & 取地址符。
📌 scanf("%d", &num); 注意取地址符！
补充
编译过程
C 程序执行
编译 → 汇编 → 链接，生成可执行文件。
💡 gcc test.c -o test 生成可执行文件
重点
ls
列出文件
list，列出当前目录下的文件和文件夹。
📌 ls -l 详细列表，ls -a 显示隐藏文件
重点
cd
切换目录
change directory，切换到指定目录。
📌 cd .. 返回上级，cd / 根目录，cd ~ 家目录
重点
pwd
当前路径
print working directory，显示当前所在路径。
💡 迷路时用 pwd
必考
mkdir
创建目录
make directory，创建新文件夹。
📌 mkdir -p 递归创建多级目录
必考
rm
删除文件
remove，删除文件或目录。
⚠️ rm -rf 强制递归删除，危险！
重点
cp / mv
复制 / 移动
cp 复制文件，mv 移动/重命名文件。
📌 cp -r 复制目录，mv old new 重命名
重点
cat
查看文件内容
concatenate，显示文件内容到终端。
📌 cat -n 显示行号
基础
clear
清屏
清空终端屏幕。
💡 快捷键 Ctrl+L
基础
whoami
当前用户
显示当前登录用户名。
💡 查看当前身份
补充
绝对路径 / 相对路径
路径表示
绝对路径从 / 开始，相对路径从当前目录开始。
📌 ./ 当前目录，../ 上级目录
必考
gcc
编译器
GNU C 编译器，将 C 源代码编译为可执行文件。
📌 gcc test.c -o test
必考
./a.out
运行程序
执行编译生成的可执行文件。
📌 ./文件名 运行程序
重点
gcc -o
指定输出文件名
gcc test.c -o myprog 生成名为 myprog 的可执行文件。
💡 不指定 -o 默认输出 a.out
重点
gcc -Wall
警告信息
显示所有警告信息，帮助发现潜在问题。
💡 建议始终使用 -Wall
重点
gcc -g
调试信息
生成调试信息，用于 gdb 调试。
📌 gcc -g test.c 生成调试版本
基础
gdb
调试器
GNU 调试器，用于调试程序运行时错误。
📌 gdb ./myprog 启动调试
基础
make
构建工具
自动化编译工具，根据 Makefile 构建项目。
💡 大型项目必备
补充
编译警告 vs 错误
区别
警告(warning)不影响编译，错误(error)导致编译失败。
⚠️ 警告也要处理，可能是潜在错误
重点
.c / .h
文件后缀
.c 源文件，.h 头文件。头文件包含声明，源文件包含实现。
📌 头文件保护：#ifndef / #define / #endif
补充
static
静态变量/函数
限制作用域为本文件，外部不可访问。
💡 模块化编程常用
📊 统计
