1. 进制基础：数码、基、位权

1.1 三要素定义 页4

数码 = 表示数的符号；基 = 数码个数；位权 = 数码所在位置对应的常数(以基为底、位置序号为指数的幂)。例 123：数码 1/2/3，基 10，位权 $10^2,10^1,10^0$，即 $1\times100+2\times10+3\times1$。

必考

1.2 四种常用进制对照 页9

十进制(基10, 0-9)、二进制(基2, 0-1)、八进制(基8, 0-7)、十六进制(基16, 0-9 A-F)。十六进制用 0x 前缀，八进制用 0 前缀。

重点

2. 进制间转换

2.1 十进制转其他（除基取余）页5

方法：连续除以基，从低到高记录余数，直至商为 0。余数逆序排列即为结果。

必考

2.2 二进制 ↔ 八/十六进制 页9

二进制转八进制：每 3 位一组(不足左补 0)；二进制转十六进制：每 4 位一组。反向操作：每位八进制用 3 位二进制代替，每位十六进制用 4 位二进制代替。

易错：分组是「从右向左」每 3/4 位一组，不足在最左侧补 0，不是右侧。
必考 (151)₈。

3. 计算机中数据的单位

3.1 单位换算 页2

bit(位)是最小单位；1 Byte(字节) = 8 bit；1 K = 1024 B；1 M = 1024 K；1 G = 1024 M；1 T = 1024 G。内存以字节为单位编址，每个字节有地址，CPU 通过地址访问。

易错：1K = 1024B = $2^{10}$B，不是 1000B；1M = $2^{20}$B；1G = $2^{30}$B。
必考

4. 原码、反码、补码

4.1 三种编码规则 页2

原码：最高位符号位，其余为绝对值；反码：正数同原码，负数符号位不变其余取反；补码：正数同原码，负数反码+1。例 +2：原码 00000010，反码 00000010，补码 00000010；-2：原码 10000010，反码 11111101，补码 11111110。

必考

4.2 为什么用补码 页5

采用补码存储：两个绝对值相同的有符号整数相加，舍弃最高位进位后值为 0。补码把减法转化为加法，简化 CPU 运算电路；0 的表示唯一(没有 +0/-0 歧义)。

重点

4.3 -128 的特殊处理 页8

8 位下原码/反码只能表示 -127~127，-128 无法表示；人为定义 -128 的补码为 10000000。因此 8 位补码范围是 -128~127。

高频

4.4 负数补码转十进制 页6

取反 10000110 → 加1 10000111 = -7。
