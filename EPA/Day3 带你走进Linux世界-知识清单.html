2. Linux 文件系统

2.1 与 Windows 的区别 页5

Linux 无驱动器符号，一切在 / 根目录下；区分大小写；用正斜杠 / 分隔路径。Windows 用 C:\Users\user1；Linux 用 /home/user1。Linux 文件系统是树形分层结构。

易错：Linux 区分大小写——File.txt 和 file.txt 是两个不同文件；Windows 不区分。
必考

2.2 目录结构 页11

/bin 二进制命令；/boot 启动程序；/dev 外部设备；/etc 配置文件；/lib 共享库；/home 普通用户主目录；/root 超级用户主目录。

重点

2.3 绝对路径与相对路径 页5

绝对路径：从根目录 / 开始的完整路径，确定不变；相对路径：相对当前位置的路径，会变化。例：故宫绝对路径是「北京市东城区景山前街4号」；从东单地铁站出发的相对路径是「坐一站地铁，出站往前 500 米右拐」。

必考
命令提示符 linux@ubuntu:~$ 中各部分含义？
参考答案linux=用户名，@分隔符，ubuntu=主机名，~表示当前在用户主目录，$表示普通用户(#为 root)。

3. Linux 七大基本命令

3.1 ls 与文件类型 页5

Linux 七种文件类型：b(块设备) c(字符设备) d(目录) l(链接) s(套接字) p(管道) -(普通文件)。ls -a 显示隐藏文件(. 开头)；ls -l 显示详细信息(七列)；. 代表当前目录，.. 代表上级目录。

必考

3.2 文件权限 rwx 页11

权限分三组：属主(user)/同组(group)/其他(other)，每组三位 rwx(读/写/执行)。例 -rwxrwxr-x：普通文件，属主 rwx、同组 rwx、其他 r-x。r=4, w=2, x=1，可数字表示如 775。

易错：对目录而言 x 表示「能否进入目录」而非「执行」，r 表示「能否读取目录内容」。
必考

3.3 cd / touch / mkdir / rm / cp / mv 页15

cd 改变目录；touch 创建空文件或更新时间；mkdir -p 创建嵌套目录；rm -rf 强制递归删除；cp -r 复制文件夹；mv 移动或重命名。cd / 根目录、cd ~ 家目录、cd .. 上级、cd - 上次目录。mv 既是移动也是重命名，取决于目标是否同路径。

易错：rm -rf / 会强制删除整个系统文件导致崩溃，使用务必谨慎！
必考
