1. 计算机系统与硬件

1.1 计算机系统的层次结构 页2

计算机系统 = 硬件(Hardware) + 操作系统(OS) + 应用软件(APP)。操作系统统一管理软硬件资源，并为 APP 开发者提供应用接口；单片机(stm32、51)等简单系统可不使用操作系统。

易错：不要把「操作系统」与「应用软件」混为一谈——OS 直接管理硬件，APP 通过 OS 提供的接口间接使用硬件。
必考

1.2 计算机的组成 页7

五大部件：输入设备、输出设备、存储器、运算器、控制器。输入设备(键盘/鼠标/摄像头)把外部信号转为电信号；输出设备(显示器/打印机)把电信号转为其它形式；存储器分主存(内存，掉电丢失)、外存(硬盘，掉电不丢失)、寄存器(CPU 内部高速存储)。

重点

1.3 CPU 的结构 页9

CPU = 运算器 + 控制器。运算器负责算术/逻辑运算（工厂里干活的工人）；控制器是指挥中心，控制 CPU 执行程序（工厂的老板）。现代 PC 通常一个 CPU 含多核心。

必考

2. 计算机的进制与数据表示

2.1 为什么计算机用二进制 页5

计算机中数据存储、运算、传输都以高低电平方式表示，高电平(5V)=1，低电平(0V)=0。数字电路用高低电平表示逻辑 1 和 0，因此二进制是硬件最自然的表达。

重点

3. 什么是程序

3.1 程序的定义 页5

程序 = 为让计算机执行某些操作或解决某个问题而编写的一系列有序指令的集合。编写程序的过程叫编程，编写者叫程序员；程序存储在磁盘上，被加载到内存中执行。

必考
广义上「程序」的含义是什么？
参考答案为了达到某个目的而计划的一系列行为（如把大象关冰箱、包饺子），计算机程序是其子集。

4. 编程语言的发展过程

4.1 三个阶段 页5

汇编语言 → 高级语言。机器语言是 0/1 序列，CPU 直接识别但难记；汇编用 add/move 等助记符，与机器码一一对应；高级语言(C/C++/Java/Python)接近自然语言，一条语句对应多条机器指令，开发效率高。

易错：汇编语言与机器语言移植性都差——不同 CPU 体系结构(x86/ARM)指令不同，机器码和汇编代码都不同。
必考

4.2 为什么要学 C 语言 页12

C 既是高级语言，又是系统级底层语言。几乎所有上层语言的底层都用 C 实现；Unix/Linux/Android/iOS/鸿蒙系统内核均用 C 编写；C 可直接操作硬件、编写驱动，是合格程序员的必经之路。

重点

4.3 计算机发展趋势 页11

两级分化：微型化(网络化/高性能/多用途) 与 巨型化(超高速/并行处理/智能化)。
