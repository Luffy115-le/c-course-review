🎴 Day5-Day8 知识卡片合集

点击卡片查看详情，按章节和分类筛选

必考
int
整型
存储整数，通常占 4 字节，范围约 -21亿 ~ +21亿。
📌 32 位系统：-2^31 ~ 2^31-1
重点
short / long
短整型 / 长整型
short 至少 2 字节，long 至少 4 字节，long long 8 字节。
📌 short < int <= long
必考
float
单精度浮点
存储小数，4 字节，约 6~7 位有效数字。
⚠️ 浮点精度有限，不能精确比较
重点
double
双精度浮点
8 字节，约 15~17 位有效数字，精度更高。
💡 默认浮点常量是 double 类型
必考
char
字符型
存储单个字符，占 1 字节，本质是 ASCII 码值。
📌 'A'=65, 'a'=97, '0'=48
重点
sizeof()
求字节数
运算符，返回数据类型或变量占用的字节数。
📌 sizeof(int) 返回 4（通常）
重点
无符号类型
unsigned
unsigned int / unsigned char 只存储非负数。
📌 unsigned int 范围：0 ~ 42亿
补充
溢出
数据超出范围
数值超出类型表示范围时发生溢出，结果不可预测。
⚠️ 整数溢出是常见错误！
重点
转义字符
特殊字符
\n 换行，\t 制表符，\\ 反斜杠，\' 单引号，\" 双引号。
📌 \n 和 \t 最常用
必考
变量初始化
赋初值
声明时赋值：int a = 10; 未初始化变量值不确定。
⚠️ 未初始化变量的值是随机的！
重点
常量
不变的值
const int MAX = 100; 或 #define MAX 100。常量不能修改。
💡 const 是类型安全的，推荐使用
必考
类型转换
隐式 / 显式
隐式：小类型转大类型自动进行；显式：(类型)值。
📌 (int)3.14 = 3，(double)5 = 5.0
重点
强制转换
显式转换
(int)(3.14) 将浮点转为整型，直接截断小数部分。
⚠️ 强制转换只是临时转换，不改变原变量类型
重点
表达式类型提升
运算时转换
char/short 在运算时自动提升为 int。
💡 'a' + 1 实际是 97 + 1 = 98
基础
标识符
变量/函数名
只能包含字母、数字、下划线，不能以数字开头，区分大小写。
📌 驼峰命名：myVariable
补充
typedef
类型别名
typedef int INT; 给类型起别名，增加可读性。
💡 常用于复杂类型，如结构体指针
重点
枚举 enum
枚举类型
定义命名常量集合：enum Week {Mon, Tue, Wed}。
📌 默认从 0 开始，可自定义值
补充
typedef enum
枚举别名
typedef enum {A, B, C} MyEnum; 简化枚举使用。
💡 常用写法
必考
+ - * / %
算术运算符
加、减、乘、除、取余。整数除法截断小数。
⚠️ 5/2=2，5%2=1，0 不能作除数！
必考
++ / --
自增 / 自减
i++ 后自增，++i 前自增。单独使用时无区别。
📌 a = ++i; 先加后赋值；a = i++; 先赋值后加
重点
优先级
运算顺序
() > 单目 > * / % > + - > 赋值。
📌 不确定时用括号！
重点
结合性
同优先级运算方向
算术运算符从左到右，赋值运算符从右到左。
📌 a = b = c; 等价于 a = (b = c)
必考
= += -= *= /= %=
赋值运算符
a += 5 等价于 a = a + 5，其他类似。
💡 简洁高效，推荐使用
重点
关系运算符
比较
> >= < <= == !=。返回 1（真）或 0（假）。
⚠️ 相等是 ==，不是 =！
必考
== 和 =
等于 vs 赋值
== 是相等比较，= 是赋值。if(a == 5) 判断，a = 5 赋值。
⚠️ 最常见错误：把 == 写成 =
基础
逻辑真 / 假
判断规则
0 为假，非 0 为真。关系表达式返回 1(真)或 0(假)。
💡 if(5) 条件为真，if(0) 条件为假
重点
浮点比较
精度问题
浮点不能直接用 == 比较，应判断差值是否小于阈值。
📌 fabs(a - b) < 1e-6
必考
&&
逻辑与
两边都为真时结果为真。短路求值：左边为假时右边不计算。
⚠️ 短路求值：a && b，a 假则不计算 b
必考
||
逻辑或
只要有一边为真结果为真。短路求值：左边为真时右边不计算。
⚠️ 短路求值：a || b，a 真则不计算 b
重点
!
逻辑非
取反，!0 = 1，!5 = 0。
📌 !a 等价于 a == 0
必考
位运算符
二进制操作
& 按位与，| 按位或，^ 按位异或，~ 按位取反。
📌 操作的是二进制位
重点
& 和 &&
位与 vs 逻辑与
& 是按位与（二进制操作），&& 是逻辑与（判断真假）。
⚠️ 不要混淆！
必考
<< >>
移位运算符
<< 左移（乘 2），>> 右移（除 2）。
📌 a << n 等价于 a * 2^n
重点
^ 异或
按位异或
相同为 0，不同为 1。常用：交换两数、判断奇偶、翻转特定位。
📌 a ^ a = 0，a ^ 0 = a
重点
条件运算符
三目运算符
条件 ? 表达式1 : 表达式2。条件为真执行表达式1，否则执行表达式2。
📌 max = a > b ? a : b
补充
sizeof vs strlen
求大小
sizeof 求字节数（包含 '\0'），strlen 求字符串长度（不含 '\0'）。
💡 char s[10] = "abc"; sizeof=10, strlen=3
重点
运算符优先级表
完整顺序
() > 单目(++--!) > 算术 > 移位 > 关系 > 位与 > 位异或 > 位或 > 逻辑与 > 逻辑或 > 条件 > 赋值 > 逗号。
📌 记不住就用括号！
