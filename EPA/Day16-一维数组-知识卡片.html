数组下标
数组下标从0开始！长度为n的数组，下标范围是0~n-1。a[0]是第一个元素，a[n-1]是最后一个。
⚠️ 最常见错误：下标从1开始或越界！

动态获取数组长度
n = sizeof(a) / sizeof(int); 或 n = sizeof(a) / sizeof(a[0]); 数组总字节数÷单个元素字节数=元素个数。

数组名是首地址
数组名a等价于&a[0]，都是第一个元素的地址。a是常量指针，不能被赋值。数组元素连续存放。
💡 a 和 &a[0] 的值完全相同
memory · 重点
连续存放
数组内存分配
数组元素在内存中连续存放，地址递增。每个元素占用相同大小。int占4字节，相邻元素地址差4。
💡 连续存放 = 可以通过首地址+偏移快速访问
memory · 必考
&a[i]
元素地址计算
第i个元素的地址 = 首地址 + i × sizeof(元素类型)。即 &a[i] = a + i。这也是为什么下标从0开始。
💡 a[i] 等价于 *(a+i)，指针运算！

sort · 必考
冒泡排序
冒泡排序思想
n-1轮比较，每轮把最大的数"冒"到后面。每轮比较次数递减：第i轮比较n-1-i次。相邻元素两两比较交换。
💡 大的数往上冒，小的数往下沉

冒泡代码
冒泡排序代码
外层i从0到n-2，内层j从0到n-2-i，if(a[j]>a[j+1])交换。总共2层嵌套循环。
💡 i控制轮数，j控制每轮比较次数
sort · 重点
flag+break
优化版冒泡排序
用flag标记是否发生交换。如果一轮没有任何交换，说明已经有序，break提前结束。对接近有序的数组效率提升明显。
💡 已有序就提前结束，不做无用功
