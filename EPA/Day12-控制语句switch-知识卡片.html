语法基础 · 必考
switch(表达式)
switch 基本结构
switch(表达式){ case 常量: 语句; break; ... default: 语句; break; }。表达式只能是整型（int/char/short/long/enum），不能是 float/double/字符串。
⚠️ 表达式类型只能是整型！包括 char（本质是ASCII码）
语法基础 · 必考
case 常量:
case 分支
每个 case 后面必须是常量（字面量或 const 常量），不能是变量。同一个 switch 中不能有两个相同值的 case。
💡 case 后必须是常量，不能是变量 n！
语法基础 · 必考
执行流程
switch 执行步骤
① 计算switch表达式的值 ② 从上到下与各case常量比较 ③ 相等则从该case开始顺序执行 ④ 遇到break跳出整个switch ⑤ 都不匹配执行default
💡 匹配到后从该case一直往后执行，直到遇到break或结束
break · 必考
break;
跳出 switch
break 用于立即跳出整个 switch 结构。99% 的情况下每个 case 后面都要加 break。忘记写 break 是 switch 最常见最隐蔽的 bug。
⚠️ 忘记 break 是最常见的错误！务必每个 case 都加
break · 重点
无break的后果
没有 break 会怎样
没有 break 时，匹配到 case 2 后会继续执行 case 3、case 4... 一直到 switch 结束。这叫做 case 穿透（fall-through）。
输出"星期二 星期三 星期四 其他"
case穿透 · 必考
多case共用
正确利用穿透
多个值执行相同操作时，让多个case共用一组语句。如 case 1: case 3: case 5: days=31; break; 让1/3/5月都共用 days=31。
✅ 这是穿透的正确用法，代码更简洁
case穿透 · 重点
fall through
穿透编程规范
故意使用穿透时，建议加注释 // fall through 说明是故意的，让其他程序员知道你不是忘记写 break。这是行业良好实践。
📌 case 1:\ncase 2:\n // fall through\n do_something();\n break;
default · 必考
default:
默认分支
default 处理所有 case 都不匹配的情况，相当于 if-else 中的最后一个 else。可以省略，但建议大多数情况都写，让程序更健壮。
💡 建议写 default 处理异常输入
default · 了解
default位置
default 的位置
default 不一定要写在最后，可以写在 switch 内的任何位置。但不管写在哪里，都只会在所有 case 都不匹配时才执行。强烈建议写在最后。
📌 可以写在任何位置，但惯例是写在最后
switch vs if · 必考
什么时候用switch
switch 的适用场景
适合：① 判断同一个变量 ② 变量值是离散的有限的整数（或字符）③ 每个分支逻辑相对独立。如：星期几、月份、成绩等级、菜单选项、计算器。
💡 switch 只能判断"等于某个值"，不能判断范围
switch vs if · 必考
什么时候用if
if-else 的适用场景
适合：① 涉及多个不同变量 ② 范围判断（如 a>10 && a<20）③ 浮点数判断 ④ 字符串判断。if-else 更灵活，能处理任意布尔表达式。
只能用 if
计算器案例 · 重点
switch(op)
简单计算器实现
用 switch 判断 char 类型的运算符。case '+': case '-': case '*': case '/':。char 可以用于 switch，因为本质是 ASCII 码（整型）。
💡 case 后面可以是字符常量如 '+'
计算器案例 · 重点
case嵌套if
switch内嵌套if
switch 内部可以嵌套 if。如做除法时：case '/': if(b==0) printf("除数不能为0"); else printf("%.2f",(float)a/b); break;
💡 switch 和 if 可以互相嵌套，非常灵活

成绩等级 · 重点
case 10: case 9:
多分支穿透示例
成绩等级中，100分和90-99分都是A级。case 10: 没有 break，穿透到 case 9: 共用 printf("A"); break;。这是穿透的经典应用。
100分和90+都是A
天数计算 · 难点
全部无break
计算当年第几天
从 case 12 往 case 1 倒序写，所有 case 都没有 break。month=3 时从 case 3 开始，累加 2 月(28) + 1 月(31) 的天数。巧妙利用穿透！
💡 经典技巧：倒序写 + 全部无 break + 巧妙穿透累加
天数计算 · 重点
闰年+1天
考虑闰年的处理
switch 计算完前几月天数后，再判断闰年：if(闰年 && month>2) sum++。注意只有当月份大于2时才需要加1天。
多加1天
菜单系统 · 重点
switch(choice)
菜单选择实现
菜单选项是 switch 最典型的应用。打印菜单后，用户输入选项，switch 根据 choice 执行对应功能。case 0 常作为退出选项。
💡 菜单 + switch = 绝配，几乎所有管理系统都这么写
常见错误 · 必考
6大易错点
switch常见错误汇总
① 忘记写break（穿透bug）② 用变量做case ③ 用浮点数/字符串做switch表达式 ④ 重复的case值 ⑤ switch后加分号 ⑥ case后是范围值（如 case 90-100:）
⚠️ 这6个错误务必记住，考试最爱考！
常见错误 · 重点
switch(n);
switch后加分号
switch(n); { case 1: ... } 分号让 switch 的语句体变成空语句，后面的 { } 是一个独立的代码块，与 switch 完全无关！和 if 后加分号是一样的坑。
⚠️ 又一个分号陷阱！switch 后面绝对不能多写分号
