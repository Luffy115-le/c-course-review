TL;DR：位运算三大应用：|(置1)、&~(清零)、^(翻转)；逻辑运算符有短路特性；三目 ? : 与逗号运算符是常考特殊运算符。

1. 位运算应用

1.1 置1：按位或 | 页2

将第 n 位置1：a |= (1 << n)。例第6位置1：a |= (1<<6) = a |= 0x40。原理：与 1 或得 1，与 0 或得原值。

必考

1.2 清零：按位与 & 页2

将第 n 位清零：a &= ~(1 << n)。例第2位清零：a &= ~(1<<2) = a &= 0xFB。原理：与 0 与得 0，与 1 与得原值。

必考

1.3 翻转：按位异或 ^ 页3

将第 n 位翻转：a ^= (1 << n)。原理：同 1 异或取反，同 0 异或得原值。

重点
如何只把变量 a 的第 3 位置 1 而不改变其它位？
参考答案a |= (1 << 3); 利用按位或，与 1 或强制置1，与 0 或保持原值。

2. 关系运算符

2.1 结果与规范 页2

关系表达式结果是 bool 类型(0假/1真)，用于条件判断和循环；二元运算符前后建议加空格。a > (b-1)，注意数学式不能直接写：10 < salary < 15 是错的，应写 salary > 10 && salary < 15。

易错：① == 是判断相等，= 是赋值，混用是经典 bug；② 建议常量放左侧 if(-1 == fd)，编译期就能发现拼写错误。
必考

3. 逻辑运算符

3.1 三大运算符 页2

! 逻辑反；&& 逻辑与(两真才真)；|| 逻辑或(一真即真)。结果都是 bool。优先级：! > 算术 > 关系 > && > || > 赋值。

必考

3.2 短路特性 页13

&& 左边为 0 时右边不再执行；|| 左边为 1 时右边不再执行。这是性能优化点：把最可能为假的子表达式放 && 最左；最可能为真的放 || 最左。

易错：int a=0; c = a++ && ++b && d++; 由于 a++ 先取值 0(假)，右侧 ++b 和 d++ 都不执行！结果 a=1, b、d 不变。
必考
闰年判断表达式 (year%4==0 && year%100!=0) || year%400==0 中，year=2000 时哪部分不会执行？
参考答案因 2000%4==0 且 2000%100==0，&& 结果为假(0)，但 || 左边为假需算右边，year%400==0 会执行并得真。若 year=2024，&& 为真，|| 短路，year%400==0 不执行。

3.3 逻辑反 ! 页10

!1=0，!0=1；任何非零值逻辑反都是 0。

4. 特殊运算符

4.1 三目运算符 ? : 页2

<条件> ? <表达式1> : <表达式2>；条件为真取表达式1，否则取表达式2。求两数最大值：max = (x > y) ? x : y; 结合性从右到左。

重点

4.2 逗号运算符 , 页7

逗号分隔多个表达式，依次运算，整个表达式值 = 最后一个表达式的值。z = (x=5, y=6, x+y); 结果 z = 11。优先级最低，结合性从左到右。

易错：逗号表达式必须用括号包裹，否则 z = x=5, y=6, x+y 会被解析为多条语句。
高频
