2. 第一个 C 语言程序

2.1 程序结构剖析 页5

#include <stdio.h> 引入输入输出头文件；int main() 是程序唯一入口；printf 是库函数；return 0 对应 main 的 int 返回值。stdio.h = standard input/output header；.h 文件叫头文件；main 函数有且仅有一个；{}内为函数体，可写多条语句。

易错：① 不引入 stdio.h 会报警告；② main 拼写不能错；③ 每条语句以分号结尾；④ 标点必须用英文符号；⑤ 花括号必须配对。
必考

2.2 输出与换行 页6

printf 双引号内为输出内容；\n 是换行符；printf 可写多行，程序顺序执行。要打印多行可用多个 printf，或在字符串中加 \n 实现换行显示。

重点
若想打印两行 "Hello" 和 "World"，最少需要几个 \n？
参考答案1 个 \n，放在 "Hello\nWorld" 中，或分两个 printf 各自带 \n。

3. 程序的运行过程

3.1 程序设计三步 页2

编译、链接 → 执行、调试。源代码(test.c)经编译器(gcc)编译为可执行文件(a.out)，再由 CPU 执行。无语法错误才能编译成功。

重点

4. C 语言特性——三高

4.1 效率高（编译型）页4

C 是编译型语言：源代码统一交给编译器，编译成机器语言并打包为可执行文件，CPU 直接执行。解释型语言(Python/JS)由解释器逐行翻译执行。编译型优点是执行效率高、缺点是跨平台能力弱、不便调试；解释型相反。

易错：编译只做一遍，以后不需重新编译——这是编译型效率高的关键；解释型每次运行都要逐句翻译。
必考

4.2 灵活度高 页8

C 提供多种运算符、底层的位操作、指针、直接操作硬件的能力。语法限制不严格，程序设计自由度大；既具高级语言易学性，又有汇编对硬件的操作能力。

重点

4.3 可移植性高 页9

C 是标准化语言，代码可在不同 OS 和计算机上运行，只需简单修改。统计表明单片机上不同机器 C 编译程序 80% 代码通用。源代码相同，经不同编译器可转为不同机器代码。

重点

4.4 如何学好 C 语言 页2

理解思路不纠结语法；多模仿、多敲、多练；改进、思考、独立编写。
