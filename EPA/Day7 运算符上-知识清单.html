TL;DR：C 运算符按优先级和结合性执行；算术/赋值/自增自减/位运算符是核心；位运算直接操作二进制位，是底层编程利器。

1. 运算符基础

1.1 运算符分类 页2

算术(+ - * / % ++ --)、关系(> < == !=)、逻辑(&& || !)、赋值(= += 等)、位运算(& | ^ ~ << >>)、三目(?:)、逗号(,)、sizeof。

重点

1.2 三个术语 页4

表达式 = 操作数+运算符；优先级高的先执行；结合性决定优先级相同时的执行顺序。a = b + 10 * c 先算 *，再 +，最后 =；类别分一元/二元/三元。

必考

2. 算术运算符

2.1 / 与 % 页3

/ 两端都是整数是整数除法(7/2=3)；只要有一个浮点数就是浮点除法(7/2.0=3.5)；% 取余只能用于整数。% 结果 = 被除数 - (商 × 除数)，例 17%5=2。

必考

2.2 应用：闰年判断与数字拆解 页6

闰年：(year%4==0 && year%100!=0) || year%400==0；拆数位：43/10=4(十位)，43%10=3(个位)。

重点

3. 赋值运算符

3.1 = 与复合赋值 页2

= 是赋值不是等号；左侧必须是变量不能是表达式；复合赋值 += -= *= /= %= &= |= ^= <<= >>=。x = x + 1 合法(取 x 加 1 存回)；x + 1 = 2 非法。

易错：a *= b + 6 不是 a*b 再加6，而是 a = a * (b+6)，因 + 优先级高于 *=。
必考

4. 自增自减运算符

4.1 前置与后置 页2

前置 ++i：先自增再参与运算；后置 i++：先参与运算再自增。单独作为语句时 i++ 与 ++i 等效。int a=20, b; b=a++ 得 b=20,a=21；b=++a 得 b=21,a=21。

易错：后置「先参与运算」是先把原值读出赋给 b，再自增 a——不是「先算完整个表达式」。
必考
int a=20, b; b = a++; a、b 各是多少？
参考答案b=20(先用原值赋给b)，a=21(后自增)。

5. 位运算符

5.1 取反 ~ 页3

~ 是单目运算符，0 变 1，1 变 0；只能用于整型，浮点型报错。int a=10; ~a = -11(因正数取反后符号位变 1)。

重点

5.2 异或 ^ 页9

^ 相异为真(1)，相同为假(0)，即「无进位相加」。性质：0^n=n；a^b=b^a(交换律)；a^b^c=a^(b^c)(结合律)。

重点

5.3 异或应用：原地交换两数 页12

a = a^b; b = a^b; a = a^b; 三步实现无第三变量交换。原理：第二步 b = (a^b)^b = a；第三步 a = (a^b)^a = b。

高频

5.4 与 & 或 | 页2

& 两都为 1 才为 1(同 1 与得原值，同 0 与得 0)；| 任一为 1 即为 1(同 1 或得 1，同 0 或得原值)。

必考

5.5 左移 << 右移 >> 页6

<< 左移 n 位 = 乘 $2^n$，右边补 0；>> 右移 n 位 = 除 $2^n$，无符号数左补 0(逻辑移位)，有符号数补符号位(算术移位)。

重点
