1. Linux 下编写第一个程序

1.1 gedit + gcc 工作流 页2

① ctrl+alt+t 开终端；② gedit first.c 编辑；③ gcc first.c -Wall 编译生成 a.out；④ ./a.out 运行。gedit 是 Linux 下的纯文本编辑器(类似记事本)；gcc 是 C 编译器；-Wall 选项尽量多显示警告。

易错：默认执行文件名 a.out，多次编译会覆盖；建议用 -o 指定名字：gcc first.c -o first -Wall。
必考

1.2 程序设计步骤 页11

编译、链接 → 执行、调试。编辑产出源代码 .c；编译链接产出可执行文件；执行调试验证结果。

2. C 语言的发展与标准

2.1 C 语言历史时间线 页2

1972 Dennis Ritchie 在 B 基础上设计 C → 1973 用 C 重写 UNIX → 1989 ANSI C(C89) → 1999 C99 → 2011 C11。

重点

2.2 C 标准演进要点 页3

C99 对 C89 的改变：for 语句内可声明变量、可变长数组。编译选项 -std=c89 / -std=c99 指定标准；-pedantic 拒绝 GNU 扩展；-pedantic-errors 遇扩展报错。

高频

2.3 GNU C 与查看 C 标准 页5

GNU C = ANSI C + GCC 扩展(如变长数组)。man gcc 搜索 -std；gcc 默认 gnu18(ISO C17 的 GNU 定制版，2018 年发布)。使用 GNU 扩展需 -std=gnu18。

了解
为何 C 语言移植性优于汇编？
参考答案C 是高级语言，源代码与特定 CPU 无关；同一份源码经不同编译器可生成对应平台的机器码，而汇编与 CPU 体系结构强绑定。
