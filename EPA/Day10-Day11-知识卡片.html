字符IO · 必考
putchar(c)
输出一个字符
向屏幕输出一个字符。参数可以是 char、int（ASCII码）或字符常量。返回值是输出字符的ASCII码。
💡 每次只能输出一个字符！不能输出字符串
字符IO · 必考
getchar()
读取一个字符
从键盘读取一个字符。返回值是 int 类型（字符的ASCII码），读到文件尾返回 EOF(-1)。
⚠️ 返回值类型是 int，不是 char！
输入缓冲 · 必考
垃圾字符
输入缓冲区问题
scanf("%d") 只读取数字，把回车符 '\n' 留在缓冲区。接下来的 scanf("%c") 会直接读走这个回车符！
💡 只有 %c 和 %s 受影响，%d %f 自动跳过空白
输入缓冲 · 重点
getchar() / %*c
处理垃圾字符方法
方法1：getchar() 吃掉回车。方法2：scanf("%*c%c",&ch) 跳过一个。方法3：scanf(" %c",&ch) 格式符前加空格。
📌 三种方法任选其一，推荐 getchar() 最直观
printf · 必考
%d %c %f %s
常用格式字符
%d=十进制整数 | %c=单个字符 | %f=小数浮点数 | %s=字符串 | %ld=长整型 | %lf=double | %x=十六进制 | %o=八进制
💡 d=decimal, o=octal, x=hex, f=float
printf · 重点
%8d %10f
宽度修饰
指定输出最小宽度。不足则左补空格，超过则按实际长度输出（不会截断）。
" 1234"（左补4空格）
printf · 必考
%.2f %10.1f
精度修饰
%.nf：保留 n 位小数（四舍五入）。%m.nf：总宽度 m，保留 n 位小数。%.ns：字符串只取前 n 个字符。
⚠️ 是四舍五入，不是直接截断！
printf · 必考
%02d
标志修饰-补零
0 标志：左边补0而不是空格。- 标志：左对齐。+ 标志：正数也显示+号。# 标志：八进制/十六进制加前缀。

scanf · 必考
& 地址符
scanf 必须用地址
scanf 的参数必须是变量的地址！scanf("%d", &age) 正确。scanf("%d", age) 错误（会崩溃）。
⚠️ C语言最经典的错误！记住 & 号
scanf · 重点
%4d%2d%2d
指定输入宽度
year=2050, month=5, day=5。
💡 常用于固定格式的日期、身份证号等解析
scanf · 了解
%*d
跳过输入数据
a=12，跳过345，b=67。
📌 * 号 = 跳过（忽略）这个数据
scanf · 重点
%lf / %f
输入输出格式区别
double 输入必须用 %lf，输出可用 %f 或 %lf。float 输入输出都用 %f。
💡 输入看类型，输出更灵活
程序结构 · 必考
顺序/选择/循环
三种基本结构
顺序结构：从上到下逐条执行。选择结构：根据条件选择（if/switch）。循环结构：根据条件重复（for/while）。
💡 任何复杂程序都由这三种结构组成
if单分支 · 必考
if(条件){语句}
if 单分支语法
条件为真（非0）执行语句块，为假（0）跳过。条件必须用 () 括起来。只有一条语句时 {} 可省略（不推荐）。
💡 非0即为真，0为假
if单分支 · 必考
= vs ==
赋值 vs 比较
if(a = 5) 是赋值，永远为真（5≠0）。if(a == 5) 才是比较是否相等。这是 C 语言最经典的坑！
⚠️ 写成 if(5 == a) 可以避免手误（常量不能被赋值）
if-else · 必考
if-else
双分支语句
条件为真执行 if 块，为假执行 else 块。二选一，互斥执行。
💡 要么走 if，要么走 else，不会都走
if-else · 必考
闰年判断
经典条件
(year%4==0 && year%100!=0) || (year%400==0)。即：能被4整除但不能被100整除，或者能被400整除。
📌 四年一闰，百年不闰，四百年再闰
多分支 · 必考
else if
多分支语句
if(条件1){...} else if(条件2){...} else{...}。从第一个条件开始判断，哪个满足就执行哪个，执行完整个结构结束。
💡 多分支是互斥的，只会执行第一个满足的
多分支 · 重点
条件顺序
条件顺序很重要
80→70→60）。如果从低到高判断，85分会先匹配到 >=60 就输出 D，逻辑错误！
⚠️ 条件顺序写反会导致逻辑完全错误
if嵌套 · 重点
if{if{}}
if 的嵌套
if 或 else 内又包含 if。先判断外层条件，满足后再判断内层条件。常用于多层逻辑判断，如三角形类型判断。
💡 嵌套层次建议不超过3层，否则可读性差
if嵌套 · 必考
悬空else
else 配对原则
else 与最近的未配对的 if 配对。没有 {} 时容易出错。建议始终用 {} 明确层次关系，避免歧义。
⚠️ 经典坑！没有 {} 的嵌套容易出错，务必加 {}！
综合应用 · 重点
变量交换
两变量交换
交换 a 和 b 需要第三个临时变量 t：t=a; a=b; b=t;。类似两杯水互换需要第三个杯子。
💡 三个数排序的基础操作
综合应用 · 重点
三数排序
三个数从小到大
if(a>b)交换ab；if(a>c)交换ac（a最小）；if(b>c)交换bc（b中间，c最大）。三次比较交换完成排序。
💡 a 先变成最小的，然后 b 和 c 再比较
综合应用 · 必考
分号陷阱
if 后多写分号
if(a>b); printf("ok"); 分号让 if 的语句体变成空语句。printf 无论条件真假都会执行！这是常见的隐蔽错误。
⚠️ if 后面不要多写分号！！！
综合应用 · 了解
门票系统
复杂条件综合
先判断月份（旺季4-10/淡季），再判断年龄段（成人/儿童/老人），两层 if 嵌套完成复杂的业务逻辑判断。
💡 真实的业务逻辑就是这样逐步判断的
