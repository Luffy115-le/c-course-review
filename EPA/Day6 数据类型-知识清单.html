1. 为什么引入数据类型

1.1 数据类型的意义 页2

同样 0/1 二进制施加不同类型(int/unsigned int)会得到不同数值。例 0xEEAABAAA：int 解释为 -290800982，unsigned int 解释为 4004166314。类型让二进制数据有了现实意义。

必考

1.2 数据类型分类 页6

基本类型(整型/字符型/实型)、构造类型(数组/结构体/共用体/枚举)、指针类型、空类型 void。

重点

2. 整型

2.1 整型取值范围 页3

char(1B, -128~127) / short(2B) / int(4B, ±21亿) / long(4或8B) / long long(8B)。每种有 unsigned 版本(只表示非负数，范围翻倍)。范围定义在 limits.h：INT_MAX=2147483647，UINT_MAX=4294967295。

必考

2.2 sizeof 运算符 页8

sizeof 获取数据类型占用字节数：sizeof(变量) / sizeof 变量 / sizeof(类型)。注意 sizeof int 是错的(类型必须加括号)；sizeof 是关键字也是单目运算符。

重点

3. 变量

3.1 变量定义与命名规则 页6

变量必须先定义后使用；命名只能含字母/数字/下划线，不能数字开头，不能是关键字，不能含空格。定义格式：类型 变量名 = 数值；例 int a = 20;。

易错：① int 1_num 错(数字开头)；② int while 错(关键字)；③ int name age 错(含空格)；④ 变量未初始化就参与运算有运行风险。
必考

4. 字符型 char

4.1 ASCII 与字符存储 页2

字符以 ASCII 码二进制形式存储；'0'=48, 'A'=65, 'a'=97。char 占 1 字节，取值 -128~127；unsigned char 0~255。字符常量用单引号 'A'，也可用 ASCII 值赋值 char c = 66。

必考

4.2 大小写与数字字符转换 页10

大写转小写 +32；小写转大写 -32；数字字符与数字差 48。'A'+32='a'；'5' - 48 = 5；数字 5 + 48 = '5'。

重点

5. 浮点型

5.1 float 与 double 页2

float(4B, 6 位精度) / double(8B, 15-16 位精度) / long double(C99)。浮点数可指数形式表示如 8E-3 = 0.008。绝大多数浮点数不能精确表示。

必考

5.2 IEEE 754 存储格式 页2

$f = (-1)^S \times M \times 2^E$，float: 1位符号+8位阶码(偏移127)+23位尾数；double: 1+11(偏移1023)+52。尾数规格化为 1.xxx 并去掉整数 1。例 9.625 = $(-1)^0 \times 1.001101 \times 2^3$，存储为 0x411A0000。

重点

5.3 浮点数比较——绝对值法 页2

浮点数不可用 == 直接比较，应判断两数差的绝对值是否小于精度。例 $|a-b| < 10^{-14}$ 则认为相等。用 fabs() 函数(需 #include <math.h>，链接 -lm)。

易错：1.0 - 0.9 ≠ 0.1！因存储精度损失，a-b = 0.0999...9778 而 0.1 = 0.10000...0555，两者不相等。float 2.2 ≠ double 2.2 但 float 2.25 == double 2.25(可精确表示)。
必考
为何 float f1 = 2.2; f1 == 2.2 为假，而 f3 = 2.25; f3 == 2.25 为真？
参考答案2.2 不能精确表示，float 与 double 的近似值不同；2.25 可精确表示，两者相同。浮点常数默认 double，故 f1(double 化)与 2.2(double)不同。

6. _Bool / bool / void

6.1 布尔类型 页3

C99 新增 _Bool(1B)，非零为真(1)、零为假(0)；stdbool.h 中 #define bool _Bool / true 1 / false 0。任何非零数值转 bool 都为 1。

高频

6.2 void 类型 页8

void = 缺省类型/无类型，用于无返回值函数和通用指针 void*。

了解

7. 类型转换

7.1 自动类型转换 页2

赋值时右值转为左值类型；二元运算按数据长度增加方向转换；所有浮点运算以 double 进行。int b = 3.14; 会丢弃小数变 3；char + int 时 char 提升为 int。

重点

7.2 强制类型转换 页7

语法：(type_name) expression。例 (int)(x+y) 把结果转 int 丢弃小数；(double)a / b 让除法按浮点进行——这是求精确商的关键。

易错：int a=100,b=3; double c = a/b; 得 33.00(整数除法)；必须 c = (double)a / b 才得 33.33。
必考
